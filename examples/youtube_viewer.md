# YouTube transcript output

The output viewer can use YouTube's native embedded player instead of `a.wav`.
Clicking an aligned word seeks and plays the video; word and phoneme highlighting
follow the video's current time. Space pauses when the transcript page has focus.
While the embedded player has focus, its own keyboard controls apply.

This example only changes playback of an **existing alignment**. It does not
download a YouTube video or align a URL. The alignment timestamps must refer to
the same video from time zero; timestamps from a trimmed clip need adjustment
before use.

## Try the playback example

From the repository root, using Python 3 (no third-party packages or models):

```sh
python3 examples/youtube_viewer.py examples/youtube_alignment.json M7lc1UVf-VE youtube-demo.html
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://localhost:8000/youtube-demo.html`. The video ID is the public example
from the [YouTube IFrame API documentation](https://developers.google.com/youtube/iframe_api_reference).
The included JSON uses **synthetic cue labels**, not a transcription of that video:
`Beginning` seeks to 0 seconds, `Five seconds` seeks to 5 seconds, and
`Unaligned example` has no timestamp and does not seek. Play through these times
to see the active cue change; press Space after clicking the transcript to pause.
The builder refuses to overwrite an existing output file.

YouTube must allow embedding of the chosen video. Internet access is required.
The page shows loading, playback-blocked and player-error messages. If a browser
blocks playback after a queued transcript click, press Play in the video.

## Use your own alignment

```sh
python3 examples/youtube_viewer.py path/to/align.json YOURVIDEOID output.html
```

Use the 11-character ID from the video's URL. Replace `YOURVIDEOID` with that ID.
Serve the output folder over HTTP or HTTPS, as above. The generated HTML includes
the alignment and video ID, so no Gentle server is required for playback.
The builder hides Gentle's download links because it creates only an HTML file.
Pages generated by the Gentle server retain their existing CSV/JSON/Zip links.

You can also set `YOUTUBE_VIDEO_ID` in `www/view_alignment.html` before generating
new Gentle outputs, or in an already exported `index.html`. Leave it empty to use
the original audio player. This template setting applies to every new output
until cleared. Existing outputs keep their own copy of the template.
The ID is stored inside the HTML, so it persists in Gentle's ZIP exports.

The YouTube player must run over HTTP/HTTPS: opening its page as `file://` can
omit the client identification YouTube requires. The viewer explains how to
serve it locally. Avoid a `no-referrer` policy; see YouTube's
[embedding requirements](https://developers.google.com/youtube/terms/required-minimum-functionality#api-client-identity-and-credentials).
Default audio exports continue to work from `file://` without loading YouTube.

## Verify changes

```sh
node --test tests/view_alignment.test.js
python3 -m unittest discover -s tests -p test_youtube_viewer.py
```

The JavaScript tests simulate player events and exercise transcript seeking,
highlighting, pre-ready clicks, pause, loading failures and the default audio
path. Actual embed availability, network access and browser playback policy
should also be checked with the example in a browser.
